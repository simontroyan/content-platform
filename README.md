# Content Platform

Учебный продукт для планирования контента. Приложение и инфраструктура развиваются вместе; первый день завершён на отдельном кластере в Multipass.

## Работа в команде

Разработчик предлагает изменения приложения в отдельной ветке и pull request. DevOps-инженер настраивает проверки, сборку, доставку и проверяет релиз. Готовых CI/CD-решений в проекте пока нет: их создание — часть практики.

- [Задание второго дня](tasks/02-release.md)
- [Условия первого дня](ЗАДАНИЕ.md)
- [Среда практики](ПРАВИЛА-ПРАКТИКИ.md)

Локальный kubeconfig находится в `.work/kubeconfig.yaml` и не коммитится. Текущий учебный кластер не является production; AWS пока не развёрнут.
