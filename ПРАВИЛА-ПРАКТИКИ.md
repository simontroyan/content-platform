# Выбранная среда практики

Обновлено 31 октября 2026 года по решению ученика.

- Локальные Linux-серверы и самостоятельная установка Kubernetes: виртуальные машины Multipass, kubeadm и отдельный kubeconfig. Учебные VM и их данные сохраняются до явного решения об удалении.
- AWS — основное облако для последующей практики: сеть, EC2, IAM, Terraform, а затем Kubernetes и связанные сервисы. Не заменять его Yandex Cloud без нового решения ученика.
- Ориентир расходов на облако — до 15 000 ₽ за месяц. Перед созданием каждого платного стенда проверить актуальные тарифы, регион, лимиты, продолжительность работы и расходы сохраняющихся ресурсов. Сумма не является гарантией стоимости.
- На Mac M1 Pro с 16 ГБ выбирать совместимые ARM-образы и контролировать общую память виртуальных машин и прочих окружений.
- Основной проект использует отдельные Multipass VM с одним control plane и одним worker; второй worker опционален по ресурсам. Существующий кластер Shift не изменяется. Облачные ресурсы в первый день не создаются.
- Инструкции в старых картах Shift, где основной учебный облачный провайдер — Yandex Cloud или первый день использует kind, не отражают этот выбор. Их ещё предстоит адаптировать; они не означают, что AWS-лаборатории уже созданы и проверены.
